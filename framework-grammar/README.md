# Framework grammar

These files are **not skills**. They are naming lookups.

`wf-audit`, `wf-plan`, `wf-prototype`, and `wf-build` read one of these after the project's convention is known. Copy this folder into the client project, or keep a checkout of this repository where the agent can see it.

- `client-first.md` — Finsweet Client-First
- `mast.md` — No-Code Supply Co. Mast

Use the file. Don't scrape Finsweet or NCSC docs unless the file is missing.

Add another documented system as `framework-grammar/<name>.md` the same way.
