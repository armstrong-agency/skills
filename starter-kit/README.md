# AI-Ready Webflow Starter Kit

Four working files for a marketing team that wants to use an AI tool on its Webflow site. They go with the free course [AI Ready Websites for Marketing Teams](https://www.armstrong.so/resources), and they are the short, by-hand versions of what the skills in this repository do for you.

| File | What it is | The skill that does it for you |
| --- | --- | --- |
| [scorecard.md](scorecard.md) | Score your site out of 25 in 5 minutes, before AI touches it. | `wf-build` reads the same things from your site. |
| [agents-md-template.md](agents-md-template.md) | A copy-paste `AGENTS.md` with publishing levels, a reuse order and a review checklist. | [`wf-folder-setup`](../skills/wf-folder-setup/SKILL.md) |
| [webflow-mcp-cheatsheet.md](webflow-mcp-cheatsheet.md) | One Webflow MCP connection per site, for Claude Code, Codex and Cursor. | [`wf-mcp-setup`](../skills/wf-mcp-setup/SKILL.md) |
| [course-index.md](course-index.md) | The five course lessons, each with one thing to do after watching. | |

Start with the scorecard. If you would like the audit and setup done for you, that is the [AI-Ready Webflow Sprint](https://www.armstrong.so/ai-ready-sprint).
