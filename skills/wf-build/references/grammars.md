# Grammars

Identify the site's naming convention from its Style Guide, existing classes and project instructions. Several signals are needed, not one class:

| Grammar | Signals | File |
| --- | --- | --- |
| Client-First | `page-wrapper`, `main-wrapper`, `section_…`, `padding-global`, `is-*` | [client-first.md](client-first.md) |
| Mast | `page-main`, `row`/`col`, `u-*`, `cc-*`, `col-lg-8` | [mast.md](mast.md) |
| Other | Lumos (`u-section`, `data-slot`) or an in-house system | None: follow the Style Guide and existing class names |

Read the matching file before naming or choosing any class. If the signals are mixed or unclear, present the candidates and wait for the user.

The Style Guide wins over the framework on class names. When they disagree, follow it and tell the user.
