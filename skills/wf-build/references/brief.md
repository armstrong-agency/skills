# The brief

Size it to the job: one section with no new pieces needs a few lines. Cover:

- **Destination:** default to a new unpublished sandbox page.
- **Sections, in order:** each one's responsibility, its Figma node or screenshot crop, and the closest existing component, class or live section. A familiar name is only a candidate, so inspect its actual responsibility, breakpoints and consumers.
- **Assemble or invent:** whether each section ships from existing pieces or needs something new.
- **Invent list:** every new class, combo, component and variable, with what was considered, why it fails, the new piece's distinct responsibility, and its proposed name.
- **Frozen:** what must not change.
- **Acceptance checks:** measurable targets at 1920, 991, 767 and 390 px when a design source exists.

When Figma or a screenshot is the source, calibrate screenshot scale first: node data proves structure, text styles, variables and measurements, while a raster proves only that capture.
