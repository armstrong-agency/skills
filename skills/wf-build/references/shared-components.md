# Changing a shared component

Follow these before changing a shared definition. Fix the component rather than unlinking an instance to avoid it.

1. Inventory instances, variants, properties, slots, nested components, default content and consumers.
2. Separate definition changes from instance overrides.
3. Record which existing behavior must stay unchanged.
4. When the blast radius is material, prototype structural work on a duplicate on the sandbox page.
5. Validate the isolated version before promoting it.
6. After promotion, verify the original and unrelated instances.
