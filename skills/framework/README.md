# Framework Skills

Framework skills provide naming and structure grammar for Webflow projects. Each framework skill contains only its specific conventions—class naming, structure patterns, and taxonomy. All framework skills pair with `webflow-build` for the implementation workflow.

## Current frameworks

- `client-first/` — Finsweet Client-First conventions
- `mast/` — No-Code Supply Co. Mast conventions

## Adding frameworks

Additional frameworks (such as Lumos or other documented systems) can be added later as `skills/framework/<name>/` following the same pattern: grammar and conventions only, with workflow delegated to `webflow-build`.
